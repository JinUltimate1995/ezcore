05

Locked principles

non-negotiable, whatever wins above
G→P

Game → Play. Never expose core / renderer / BIOS / config before the first frame. Auto-pick the core, remember it.

1AC

One accent color. Cyan OR amber OR lime — never two. No gradients-for-fun, no RGB gamer clutter.

48PX

Logo must read at 48px. If the mark dies small, it dies. Test every concept as a home-screen icon.

TACT

Every tap answers. Early-iPhone rule: press states, haptics, spring physics. Nothing feels dead.

BYOD

Bring your own dumps. No Nintendo marks, no ROM talk in UI copy, no gray-area buttons. Ever.
